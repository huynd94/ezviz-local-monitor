## Findings fixed during live testing

1. Optional .NET LTTng plugin depended on liblttng-ust.so.0 unavailable on Ubuntu24.04. Omitted from candidate distribution; application file/journald/EventPipe logging remains supported.
2. Rollback reset-failed could fail when systemd unloaded a disabled/inactive unit. Reset only a failed unit, then start loads unit file normally; confirmed with real failed doctor rollback.

## Stable release decision

Implementation/build artifacts can be reviewed as prerelease candidates. Do not publish stable v1.9.0 until real-camera, reboot and 24-hour gates are recorded. No tag, remote release or production deployment is authorized by this evidence file alone.
